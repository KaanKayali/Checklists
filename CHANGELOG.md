# Changelog

## [1.0.1] - 2026-11-10
- Refined UI matching the wireframe and reference layout.
- App identity: Checklists with "Boards" structure and zero sample data initial state.
- Larger, more prominent white checkmark on brand logo badge.
- Transparent navigation headers across both Overview and Detail views.
- Larger titles and small rounded rectangle badge for version `v1.0.0`.
- Footer with `@KaanKayali` in gray.
- White circular buttons (`.btn-circle`) for 3-dots menus, back button, and undo button.
- Horizontal 3-dots icon (`···`).
- Pinned section collapsible with yellow chevron toggle.
- Board cards with divider lines, title wrapping, and exact timestamps (only time for today, only Yesterday, or date; no "edited" wording).
- Section separator lines between sections (no line directly under section title).
- Mobile bottom toolbar capsule with Add Day, Cross Out, and Clear Text with backspace (`⌫`) icon; standalone circular Add Task button that immediately focuses the input and opens the virtual keyboard.
- Removed yellow selected outline and removed strikethrough from completed checkmarks.
- Homescreen 3-dots menu now houses Select Boards, Sort By (with subtitle `Default (Date Edited)`), Dark Mode toggle with icons, and Settings.

## [1.0.0] - 2026-11-10
- Initial release of the "Checklists" PWA.
- LocalStorage persistence with JSON Import/Export.
- Bilingual support (English & German).
- Responsive layout for iPhone (Add to Home Screen) and Laptops.
- Custom #ffc114 theme, Bierstadt typography, and dark mode support.
