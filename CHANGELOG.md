# Changelog

## [1.0.0] - 2026-11-10
- Initial release of the "Checklists" PWA.
- LocalStorage persistence with JSON Import/Export.
- Bilingual support (English & German).
- Responsive layout for iPhone (Add to Home Screen) and Laptops.
- Custom #ffc114 theme, Bierstadt typography, and dark mode support.
- Circular badge checkmark styling and swipe-to-delete mobile gestures.
- Undo stack for instantaneous action reverts.
- Cursor logic applying edit operations to the active line position.
